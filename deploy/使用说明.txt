============================================================
  文具店销售管理系统 - 使用说明
============================================================

欢迎使用文具店销售管理系统！

请根据你的操作系统选择对应的安装指南:

  Windows 用户 → 打开 "Windows安装指南.txt"
  Mac 用户     → 打开 "Mac安装指南.txt"

首次使用需要完成以下步骤:
  1. 安装 MySQL 数据库
  2. 初始化数据库 (运行 init_db 脚本)
  3. 启动系统 (运行 start 脚本)

之后每次使用只需运行 start 脚本即可。


============================================================
  系统功能一览
============================================================

  首页看板     — 今日销售、库存预警、销售排行、热力图
  库存管理     — 商品的增删改查、库存预警
  销售管理     — 销售记录、筛选排序
  进货管理     — 进货记录管理
  高级搜索     — 按类型/关键词/日期范围等条件筛选
  AI 智能助手  — 自然语言查询销售库存数据


============================================================
  技术支持
============================================================

  如遇问题，请检查:
  1. MySQL 是否已安装并启动
  2. 数据库是否已初始化 (运行过 init_db 脚本)
  3. 是否按照安装指南的步骤操作
